# **App Name**: Dashboard Central

## Core Features:

- Role-Based Login Forms: Implement distinct login forms for Admin, Client, Valuer and Customer dashboards, with toggle functionality.
- Firebase Admin Auth: Integrate Firebase Authentication for the Admin dashboard using the provided API key and configuration details.
- Admin Dashboard: Create an admin dashboard with access controls configured with the proper authentication keys
- Client Dashboard: Create a dedicated Client dashboard upon login.
- Valuer Dashboard: Design a dedicated Valuer dashboard, displayed post-login.
- Customer Dashboard: Implement a distinct Customer dashboard upon login.

## Style Guidelines:

- Primary color: A vibrant blue (#3498db) for primary interactive elements and calls to action, conveying trust and stability.
- Background color: Light grey (#f8f9fa) providing a clean and neutral backdrop to ensure readability and focus on content.
- Accent color: A deep grey (#2c3e50), used sparingly for important notifications or highlights to draw attention without overwhelming the user.
- Headline Font: 'Raleway' (sans-serif) for headings. Body Font: 'Open Sans' (sans-serif) for general text.
